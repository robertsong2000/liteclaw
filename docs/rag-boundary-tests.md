# RAG 边界测试对照清单

Web UI 建议问题（第二行"边界测试"，含第一行"基础"）的预期输出对照表。
悬停在问题按钮上会显示同款"预期"提示；点击发送后，拿回答对照下表即可判定通过/失败。

## 两类测试，通过标准相反

| 类别 | 手册里有没有 | 什么叫通过 | 什么叫失败 |
|---|---|---|---|
| **命中**（正样本） | 有 | 只按检索到的原文作答，数字/警告措辞原样，结尾附页码引用 | 脱离检索内容凭记忆作答、数字改动、漏页码 |
| **拒答**（负样本） | 必然没有（纯电车，无机油/汽油系统） | 明确说"手册中未找到"，可建议查保养文档或联系经销商 | 编造周期/位置，或把无关检索段落（胎压、清洁等）硬凑成答案 |

两类都必须先走 `skill_run("manual-rag", ...)`，跳过检索直接回答直接算失败。

## 基础组（命中）

| 问题 | 预期输出 | 失败信号 |
|---|---|---|
| 儿童安全座椅怎么安装？ | 按 Child safety 章节：ISOFIX 锚点位置（靠背与坐垫间环形标记，参考 p.91–98）、安装要点，附页码 | 无页码；锚点描述与手册不符 |
| 胎压警告灯亮了怎么办？ | 按 Tyre pressure loss warning（参考 p.180–183）：停车检查冷态胎压、按胎压标签复位 | 编造"立即拖车"之类手册没有的处置 |
| 充电需要多长时间？ | 说明时间随充电功率不同，引用手册数值/表格，附页码 | 给出一个拍脑袋的固定小时数 |
| 冬天续航里程为什么会下降？ | 按手册解释低温对续航的影响并给建议，附页码 | 凭常识泛泛而谈，无检索依据 |
| 保养周期是多久？ | 手册把具体周期指向单独保养文档——如实转述"见保养文档"并附页码 | 编出具体公里数/月数 |
| 雾灯怎么开？ | 按照明章节：操作方式 + 前提条件（如先开近光），附页码 | 只凭常识描述，无引用 |

## 边界测试组

### 命中（应答）

| 问题 | 预期输出 | 失败信号 |
|---|---|---|
| 轮胎的标准胎压是多少？ | 手册**不含具体数值**：p.332（PDF p.334）仅为标签说明图（B 尺寸 / C 前胎压 / D 后胎压），实际数值在驾驶员车门 Label A。应指向 Label A，并转述：冷态检查、无法冷测加 0.2–0.3 bar（3 PSI）、热胎禁止放气，附页码 | 编造任何具体 bar/PSI 数值；漏掉"看车门标签"这个指向 |
| 千斤顶应该支撑在车底什么位置？ | 手册规定的支撑点位置 + 安全警告（仅在指定点举升），附页码 | 说不出具体位置或漏掉警告 |
| 车钥匙电池没电了怎么更换？ | 更换步骤 + 电池型号，附页码 | 漏型号；步骤与手册不符 |
| 12伏蓄电池亏电了怎么办？ | 应急启动/充电说明（含电动车注意事项），附页码 | 用燃油车思路乱答 |
| 长途出行前应该检查哪些项目？ | 综合多章节的检查清单，引用多条页码（≤4 条） | 单一来源以偏概全 |

### 拒答（应说"未找到"）

| 问题 | 为什么手册必然没有 | 预期输出 | 失败信号 |
|---|---|---|---|
| 发动机机油多久换一次？ | 纯电，无发动机 | 明确说未找到；可建议查保养文档/经销商 | 编周期；或引用胎压/清洁等无关段落硬答 |
| 汽油滤芯多久换一次？ | 纯电，无汽油系统 | 同上 | 同上 |
| 油箱盖开关在哪里？ | 纯电，无油箱 | 同上 | 同上 |

## 判定速记

- 命中题：**有页码 + 内容对得上 = 过**；没页码或内容对不上 = 挂。
- 拒答题：**答"没找到" = 过**；答出任何具体内容 = 挂。
- 任何题：没调 manual-rag 就作答 = 直接挂。
