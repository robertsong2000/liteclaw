01 / 能力

what it does一只小龙虾能干什么

F.01💬

Web 对话界面 chat ui

浏览器打开即用。流式输出、Markdown 渲染、可折叠 <think> 推理、TPS 吞吐率显示。会话历史持久化,侧边栏随时切换。

F.02🤖

Agent Loop reason → tool → observe

模型自主多轮调用工具:读文件、搜索、写文件、跑命令、调 skill。reason → tool_call → observe → decide 循环,带迭代上限防失控。

F.03🛡️

Defender 安全内核 defender-first

内嵌 clawdefender 规则引擎。prompt injection、危险命令(rm -rf /、reverse shell)、路径穿越——在每次执行前拦截,不是事后补救。

F.04🔧

9 个内置工具 function calling

read / grep / glob / fetch / write / edit / bash / audit / skill。只读工具自动执行,写操作需确认。支持 OpenAI function calling 的模型即可用。

F.05🧩

Skill 原生 78+ skills

自动发现 ~/.agents/skills 与项目本地 skill。模型在对话中可 skill_list 查看、skill_run 执行——飞书、搜索、安全扫描等 78+ skill 即装即用。

F.06🔌

MCP Server claude / cursor

lc mcp 一键启动 stdio JSON-RPC server,把所有能力暴露给 Claude Code、Cursor 等 MCP 客户端。同一套工具,换个宿主。

F.07🐳

容器部署 one command

Dockerfile 多阶段构建 + docker-compose 一键编排。挂载源码与 skill 池,cargo 缓存持久化,容器内增量编译。

F.08⏹️

可中止 + 确认 human-in-loop

流式响应中途可一键 abort。write / edit / bash 等变更操作弹「允许/拒绝」确认卡;勾选自动模式则全部免确认。

F.09⚡

资源极省 lean-first

纯 Rust 静态二进制,opt-level z + LTO + strip。rustls 而非 openssl,ignore 而非完整 ripgrep。CI 断言 < 5MB。

02 / agent loop

reason · tool · observe模型自主干活的安全循环

给模型一组工具和一段对话,它自己决定调哪个、传什么参数、怎么解读结果——直到任务完成。 每个工具调用都过 Defender,每个写操作都经你确认。循环有上限,不会失控。

🧠

🛡️
defender

👁️

04 / 上手

three ways to run三种方式,挑你顺手的

WAY · 01

本地直接运行

最简单 · 需 Rust
# 编译 + 启动 Web UI $ cargo build --release $ ./target/release/lc serve 9999 # 浏览器打开 # → http://localhost:9999
WAY · 02

Docker 部署

一键 · 无需本地 Rust
$ docker compose up -d # → http://localhost:8080 # 容器内访问宿主 Ollama: # base_url 填 # host.docker.internal:11434/v1
WAY · 03

纯 CLI 工具

不需要模型
$ lc read README.md $ lc grep "async" crates/ $ lc audit . $ lc skills
配置模型 · 任意 OpenAI 兼容端点
# 浏览器顶部配置栏,或直接编辑 ~/.liteclaw/config.json
# 支持的后端:
#   Ollama        http://localhost:11434/v1       (本地 · 免费)
#   LM Studio     http://localhost:1234/v1        (本地 · GUI)
#   NewAPI/OneAPI http://your-gateway:port/v1     (自建网关)
#   OpenAI/GLM/DeepSeek 云端 /v1                  (官方 API)
#
# ⚠ 模型须支持 function calling 才能自动调工具(MiniMax-M3 / Qwen3 推荐)
