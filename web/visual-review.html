01 / ARCHITECTURE

离线准备，在线按需选择。

文字索引和图片目录各司其职。图片主要通过文字命中、页码与明确关联进入候选集，目前没有独立的图片向量索引。

离线资产构建PER MANUAL REVISION
① PDF + JSONL

PDF 提供原图；JSONL 提供检索片段，manifest 补充跨页关联。

② 渲染与裁剪

160 DPI 渲染页面；裁剪插图和图标，保留叠加的编号。

③ 对话视觉标注

查看裁剪图与页图，记录描述、图文关联、问题和证据。

④ 合并图片目录

校验文件哈希，把模型描述写入 catalog 的标题与上下文。

在线问答请求PER QUESTION
① 文字混合检索

问题向量 + 本地 BM25；通过 RRF 合并排名，找到手册片段。

② 图片候选召回

页码范围 ±1、chunk_id 和关键词关联；本地排序最多保留 48 张。

③ DeepSeek 选图

有候选时额外调用文本接口，通常选 1 张，最多 3 张。

④ 文字回答与展示

答案模型生成文字；前端展示精选插图，原始页折叠、按需加载。

“离线”描述的是处理时机。 本轮标注使用当前对话的视觉能力，结果保存在本机；不是本机部署了视觉模型。在线 DeepSeek 仍会参与选图，但请求里只有文字元数据，没有图片像素。
02 / DATA CONTRACT

一张图，需要两层记录。

保存原始证据和模型判断，才能在手册更新、标注纠错和迁移部署时知道哪些内容需要重新检查。

A / 原始资产与关联

catalog.json + PNG

id / file
由源 PDF 内容哈希、页码和图号组成稳定标识，定位裁剪文件。
source / page
源 PDF 与 PDF 页序号；不一定等于书上印刷页码。
chunk_ids
显式绑定文字片段；例如保险丝说明表和实物图不在同一页。
alt_text / context
在线选图读取的文字；应用视觉标注时保留原始标题与上下文备查。
B / 模型判断与证据

visual-reviews.jsonl

caption
这张图叫什么，例如“启动按钮 2”。
description
图中对象、编号、箭头等可见内容。
association
图片与页内原文、操作步骤的对应解释。
evidence / hashes
裁剪图、整页图和哈希；哈希改变会使已有核验失效。
human_review
本轮记录为 pending。模型通过不等同于人工批准。

04 / LIMITATIONS

已经能用，还缺什么？

以下区分代码事实、数据现状和风险推断。模型标注是新的证据来源，同时也是需要验证的数据。

P0 · 数据质量 / 已观察

覆盖完成，复核未闭环

模型标记 679 条通过，人工批准 0 条；584 条布局审查队列仍存在。汇总的 needs_human_review=0 只统计模型主动标疑项。

影响：此前“无需人工复核”的结论过强。需要逐项核对质量，不能只看完成计数。

P0 · 标注语义 / 需验证

文字说明可能带偏选图

同页多图、编号复用、符号裁剪夹带正文都会增加误标概率。哈希只证明文件一致，无法证明模型描述正确。

影响：DeepSeek 不看像素，错误说明会沿着检索和选图继续传播。

P1 · 召回 / 代码事实

中文描述与英文排序不匹配

本地 shortlist 用英文词正则与有限中文别名；视觉标注大量使用中文。候选截断为 48 张前，相关图可能没有获得有效排名。

影响：即使后续模型足够强，也选不到已被过滤掉的正确图片。

P1 · 结构 / 代码事实

页码相近不等于语义相关

三栏布局启发式、相邻页范围和 0.55 相似度门槛偏向当前 R5 数据。跨页表格、纯矢量图或其他手册需要专门验证。

影响：可能漏图，也可能引入同章节但不同操作的插图。

P0 · 可靠性 / 已复现

图片成功，文字仍可能失败

选图用 Python，正文用 Rust，网络配置行为不同。本次已复现 SOCKS 代理协议不被 Rust 客户端支持；文字失败的网页提示已补上。

影响：用户看到图却没有回答。仍需统一网络策略并保留底层错误原因。

P1 · 时延与验证 / 代码事实

额外调用缺少效果度量

选图请求超时设为 25 秒，异常返回空图；AUTO-RAG 路径中选图位于正文生成之前。目前未见选图缓存，也缺少完整图像人工金标准。

影响：新增等待和调用成本，缺图原因不直观；代码测试通过不能证明语义准确率。

05 / NEXT ITERATION

先建立可信度，再扩大能力。

以下均为后续建议，不表示已经实现。保留 DeepSeek 在线选图；在线多模态看图按你此前的要求暂缓。

01 / P0

标注审查与状态统一

合并模型结论、布局疑点和人工签核口径。优先复核安全相关图、同页多图、截断符号、跨页表格；记录修改前后和复核人。

验收证据每条疑点有明确处置；未解决项仍留队列。抽样报告记录错误类型与分母，不以覆盖率冒充准确率。
02 / P0

正文与选图的失败可见

统一代理配置与启动检查，保留错误链；分别记录检索、选图、正文阶段的结果和耗时。正文失败明确提示，选图失败允许纯文字回答。

验收证据连接失败、超时、空回答等用例不会静默结束；日志可定位阶段且不输出密钥。
03 / P1

跨语言召回与选图评测

改进中英文分词；评估为图片描述建立独立文本向量索引，保留显式 chunk 关联。建立包含“应该不出图”的问题集。

验收证据用同一数据版本对比候选召回率、Top-1 正确率、误配率和多步骤覆盖；阈值由评测确定。
04 / P1

缩短等待与版本化交付

按问题、目录版本和模型配置缓存选图；评估正文与选图异步展示。为 PNG、目录和标注建立统一版本清单，打包迁移并校验哈希。

验收证据记录 p50/p95 时延和缓存命中率；改标注后缓存失效；本地与容器使用相同资产版本。
05 / P2

可重复的离线标注流水线

支持模型版本、提示词版本、批次记录、断点续跑与差异复核。先改善离线处理的可重复性；在线视觉二次校验保持暂缓。

验收证据同一批次可追溯和重跑，失败项可恢复，PDF 变更后只对相关资产重新核验。
06 / VERIFICATION & TRACEABILITY

用什么证明下一轮更好？

功能正确、语义正确和响应稳定是不同维度，需要分别验证。下列验收指标是建议，页面不编造尚未测量的成绩。

维度当前依据下一轮要补的证据
资产与来源文件哈希、页码关联、图片目录与路径校验。完整资产版本清单、迁移后的完整性检查。
图文语义679 条模型记录；人工批准为 0。人工审定的正确图片 ID 集合，含相似图和无图反例。
前端交互已有回归脚本覆盖图片复用、旧图清除、折叠原页和放大。图成功但文失败、迟到的图片、重试与切换会话的状态测试。
运行稳定性已定位代理协议差异；已有错误反馈修复。分阶段成功率、时延分布、故障注入和可定位日志。
